## 2. 技术基线（已核实，含证据）

| 结论 | 处理 | 证据 |
|---|---|---|
| Vapor 下页面 `onLoad/onShow/onReady/onHide/onUnload` 不支持 | 不用这些钩子，不用 URL query 传参 | `docs/page.md:211-215` |
| `onMounted/onUnmounted` 文档也标 Vapor 不支持，但官方示例在用 | **必须先 Spike 验证**，不过则关 Vapor | `docs/vue/composition-api.md:3163-3165` |
| 跨页共享状态：独立 `.uts` 导出全局 `reactive` | 采用，`globalData`/`globalThis`/`provide` 均不可用 | `docs/tutorial/store.md:11`、`docs/vue/global-api.md:16-21` |
| `playbackRate` 仅 `0.5/0.8/1.0/1.25/1.5/2.0` | 慢速台词用 **0.8** | `docs/api/create-inner-audio-context.md:74` |
| `@keyframes`/`animation` 不支持；`transition` 不可用于 flatten 节点 | 动效 = JS 定时器 + 非 flatten 的 transition | `docs/css/css_diff_web.md:531-555,681-687` |
| 存储/音频/swiper/scroll-view/aspectFit/touch 事件/定时器 | 均可用 | 同目录对应文档 |
| 中文 TTS：Huihui / Yaoyao / Kangkang；ffmpeg 已装 | 22 条占位音可本地生成 | 注册表 `Speech_OneCore\Voices\Tokens` |

**统一写法**：页面用 `<script setup lang="ts">`（与现有一致），工具文件用 `.uts`；所有类型显式声明，不用 `any`；文本一律 `<text>`；只用 flex 与 `v-if`。

## 4. 数据与口径

### 4.1 类型（`data/types.uts`）

```ts
export type Option = { id: string, label: string, image: string }
export type Question = {
  id: string, kind: string,            // 'identify' | 'judge'
  teachText: string, teachAudio: string, teachImage: string,
  promptText: string, promptAudio: string,
  options: Option[], answerId: string
}
export type Scene = { id: string, name: string, cover: string, questions: Question[] }
export type Profile = { id: string, name: string, avatar: string, createdAt: number }
export type Trial = {
  id: string, childId: string, sceneId: string, qid: string,
  optId: string, ok: boolean, hint: number, ms: number, ts: number
}
export type SessionCfg = { childId: string, sceneId: string, count: number }
export type SessionResult = { cfg: SessionCfg, trials: Trial[], startTs: number, endTs: number }
```

### 4.2 存储（`utils/storage.uts`）

| 键 | 内容 | 上限 |
|---|---|---|
| `asd_profiles` | `Profile[]` | 20 |
| `asd_active_child` | 当前孩子 id | 1 |
| `asd_trials` | `Trial[]`，全孩子混存，按 `childId` 过滤 | 2000，超出从头截断 |
| `asd_settings` | `{ volume, showText, autoVoice }` | 1 |

```ts
export function loadProfiles(): Profile[]
export function saveProfile(p: Profile): void        // 有则更新，无则追加
export function deleteProfile(id: string): void      // 级联删该 childId 的 trials；若删的是当前孩子，active 切到第一个
export function getActiveChildId(): string
export function setActiveChildId(id: string): void
export function appendTrial(t: Trial): void
export function loadTrials(childId: string): Trial[] // 返回 ts 升序
export function clearTrials(childId: string): void
export function loadSettings(): void                  // 读入 store.state
export function saveSettings(): void
```

**两条硬规则**
1. **读回必须逐字段重建对象**。`getStorageSync` 读回的是 `UTSJSONObject`，不能直接 `as Trial[]`，否则运行期崩。所有转换集中在 `storage.uts`，页面不许自己 parse。
2. **只写 JSON 字符串**：`setStorageSync(key, JSON.stringify(...))`。

### 4.3 统计口径（先定死，否则报告必返工）

| 字段 | 口径 |
|---|---|
| `ok` | 仅第一次作答就正确 = `true`；重教后对、公布答案都算 `false` |
| `hint` | 0 = 一次通过；1 = 重教后通过；2 = 公布答案 |
| `ms` | 从进入 `ask` 到本次点击的毫秒数；第二次作答覆盖第一次（记最终那次） |
| 一题一条 Trial | 同一题在一轮里只产生 **1 条**，在题目结束时一次性写入，不在每次点击时写 |
| 一次通过率 | `hint==0` 题数 ÷ 本轮题数 |
| 平均反应时 | 只统计 `hint==0` 的 Trial；无数据时显示 `—` |
| 星级 | ≥80% 三星，≥50% 二星，其余一星 |

## 5. 页面 UI 详设

> 尺寸沿用现有代码的 `px`。Spike 阶段在 K70 上截图校准一次，若整体偏小则统一换 `rpx`，**只改单位不改数值结构**。

### 5.1 home

```
view.page(flex:1, column)
 ├─ view.top(padding 24)         当前孩子：头像 56px 圆 + 名字 22px + 右侧「切换」18px
 ├─ view.menu(flex:1, 居中, 间距 20)
 │   ├─ btn.primary  开始训练     宽 80%，高 88px，圆角 24，字 28
 │   ├─ btn.normal   我的绘本     宽 80%，高 72px，字 24
 │   └─ text.sub     已训练 N 次  字 16，#8A9BB0
 └─ view.hotzone(右下 72×72)     长按 5 秒进 parent，按住显示 36 段进度环
```

- 状态：`profiles` 为空时，顶部显示「先建一个档案」，`开始训练`置灰，点它跳 profiles。
- 进度环：36 根 2×8px 小条，`v-for` 预计算角度，按进度改透明度；`@touchstart` 起 `setInterval(50ms)`，`@touchend/@touchcancel/@touchmove(位移>20px)` 取消；满 5000ms 且未导航过才 `navigateTo parent`（导航锁）。
- N = 当前孩子 `trials.length`。

### 5.2 setup

```
顶部返回(仅家长可点) + 标题「选一个场景」
场景卡片横排 2 张：封面图(宽 44%, 高 140) + 名字 22px，选中态 3px 主色描边
题量：两个胶囊「4 题」「8 题」
开关行：显示文字 / 播放语音（switch）
底部主按钮「开始」高 80px
```

- 默认：上次场景、4 题、两个开关开。
- 点「开始」→ `startSession({childId, sceneId, count})` → `navigateTo session`。**不传 URL 参数**。
- 未选场景时按钮置灰。

### 5.3 session（核心）

```
view.page
 ├─ 顶部：进度「第 2 / 4 题」16px + 进度条高 4px
 ├─ 中部：教学图/题干图  宽 100%，高 300px，aspectFit
 │        phase==='teach' 显示 teachImage；否则显示题干图（identify 用 teachImage 亦可）
 ├─ 台词区：文本 26px 居中（showText 关闭时隐藏）
 │        + 声波条 3 根 6×(6~22)px，播音频时 120ms 变高，否则静止
 └─ 选项区：两张卡片各 44% 宽、220px 高、圆角 24、间距 16
            identify：图 + 短文案；judge：对/不对图标 + 文案
```

**状态机**

| 当前 | 触发 | 动作 | 下一状态 |
|---|---|---|---|
| teach | 音频 `onEnded` 或 4s 超时 | 停止声波，记 `askStartTs` | ask |
| ask | 点选项且未锁 | 立即上锁，`ms = now - askStartTs` | 判定 |
| 判定 | 答对 | 写 Trial(ok=true,hint=0)，星尘 + 正确音 1.2s | next |
| 判定 | 答错且 attempt=1 | 卡片摆动 300ms，播「再看一看」 | reteach |
| reteach | 2.5s 到 | 高亮正确选项，`attempt=2`，解锁，重置 `askStartTs` | ask |
| 判定 | 答对且 attempt=2 | 写 Trial(ok=false,hint=1)，播「这次对了」 | next |
| 判定 | 答错且 attempt=2 | 写 Trial(ok=false,hint=2)，答案放大、错误项透明 0.4，播「答案是…」2.5s | reveal → next |
| next | 还有题 | `qIndex++`，解锁 | teach |
| next | 无题 | `finishSession()` | `redirectTo result` |

**异常与锁**
- 任何 `ask` 之外的阶段点击选项一律忽略。
- `onUnmounted`（若 Spike 验证可用）清定时器 + `audio.stop()`；不可用则用 Spike 确定的替代钩子。
- 音频加载失败必须走同一完成回调，**不许死等**（否则整轮卡死）。
- 连续双击只记一次（上锁在判定前）。

### 5.4 result

```
星级（3 个大星 64px，按星级点亮）
主文案 24px：「一次答对 X 题，重教 Y 题」
错题回顾列表：hint>=1 的题，每行 = 题号 + 教学句 + 「再听一遍」按钮
底部两按钮：再玩一次（同场景重开）/ 看绘本
```

- 数据只从 `store.state.result` 读，**不重新查存储**。
- 直接按返回键离开本页时，`result` 保留在 store，下次开始训练才覆盖。

### 5.5 book

```
swiper（每场景一屏，indicator-dots）
 └─ swiper-item：场景名 24px + 2×2 卡片网格
      卡片 = 题目图 + 一句教学短句，点击播 promptAudio
```

- 卡片复用 `SCENES` 数据，不另建内容文件。
- 播放中卡片有描边；再点其他卡片先 `stop()`。

### 5.6 parent

```
顶部：当前孩子名 + 「切换档案」
三 tab：记录 / 统计 / 设置（页内自绘，不用 uni-tab-bar）
记录：倒序列表，行 = 场景·题号 · 结果标签 · 反应时 · 时间
统计：两场景各一行（一次通过率、平均反应时）+ 近 7 天完成题数
设置：音量滑块、显示文字开关、清空当前孩子记录（二次确认）
```

- 结果标签色：一次通过 `#4CC38A`、重教 `#7FB2EF`、公布答案 `#F2A65A`。
- 空态：记录为空显示「还没有训练记录」。

### 5.7 profiles

```
列表：头像 56 + 名字 22 + 「当前」标记；点击行 = 设为当前并返回
底部「新增孩子」：名字输入框 + 4 个预选头像 + 保存
每行右侧「删除」：弹确认「会同时删除该孩子的全部记录」
```

- 至少保留 1 个档案：删到最后一个时禁止删除并提示。
- 新增后自动设为当前。

## 8. 验收用例（逐条勾选）

**主流程**
- [ ] A1 首页 → 开始训练 → 选「过马路」4 题 → 能进入第 1 题教学段并听到语音
- [ ] A2 第 1 题一次答对：星尘 + 音效 + 自动切题，记录 `ok=true,hint=0`
- [ ] A3 第 2 题第一次答错：无「错了」字样、无红叉，播「再看一看」并高亮答案
- [ ] A4 第 2 题第二次答对：记 `ok=false,hint=1`
- [ ] A5 第 3 题连续两次答错：公布答案、错误项变灰，记 `hint=2`，仍继续下一题
- [ ] A6 4 题结束进结果页，「一次答对 X / 重教 Y」与实际作答完全一致
- [ ] A7 教学段与答题段连点选项 10 次，不产生重复记录、不跳题
- [ ] A8 把某条音频改名制造缺失，流程仍能走完整轮（不卡死）

**数据与档案**
- [ ] B1 杀进程重开，训练记录与当前孩子仍在
- [ ] B2 新建第二个孩子，其记录列表为空，与第一个孩子完全隔离
- [ ] B3 切换孩子后，home 的「已训练 N 次」与 parent 统计同步变化
- [ ] B4 删除孩子后，其记录一并删除，且当前孩子自动切换
- [ ] B5 只剩一个档案时无法删除
- [ ] B6 同一题在一轮里只产生 1 条记录

**家长端与绘本**
- [ ] C1 home 右下角短按不进 parent；长按 5 秒才进，中途松手进度清零
- [ ] C2 按住后移动手指超过 20px，长按被取消
- [ ] C3 统计页「平均反应时」只含一次通过的题；无数据时显示 `—`
- [ ] C4 绘本两场景可翻页，点卡片朗读，连点两张不叠音
- [ ] C5 清空记录需二次确认，且只清当前孩子

**通用**
- [ ] D1 关闭「显示文字」后，仅靠语音与图片也能完成一轮
- [ ] D2 关闭「播放语音」后，流程不卡在等待音频结束（走超时分支）
- [ ] D3 全程无系统返回键误退；结果页可正常返回首页

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| Vapor 下页面钩子不触发 | S0 先验证；失败仅改 `manifest.json` 的 `vapor`，不动业务代码 |
| 音频旧回调串台 / 重复监听 | 单例 + 固定监听 + 播放序号 token；`onEnded`/`onError` 统一完成 |
| 存储读回类型不是 `Trial[]` | 全部转换集中在 `storage.uts`，页面禁止自行 parse |
| 插画风格不统一、人物换脸 | 先 6 张定风格，确认后再批量 |
| 双击/连点产生脏数据 | 判定前上锁，一题一条 Trial |
| 统计口径各页不一致 | §4.3 为唯一口径，result 与 parent 共用同一组计算函数 |
| px 在 K70 上偏小 | S0 截图校准，必要时统一改 rpx |
